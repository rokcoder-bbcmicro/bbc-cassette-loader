BBC Micro Cassette Loader

Recover standard BBC Micro cassette files from WAV recordings or live line-in audio.

Importing a cassette

  1. Choose Input > Import WAV... and select one or more recordings.
  2. For difficult recordings, enable Use recovery passes. This takes longer and combines CRC-valid results from eight decoding profiles, including an alternate phase alignment for phase-shifted tones.
  3. Attempt conservative CRC repair is optional. It tries only unique low-confidence bit changes accepted by the cassette CRC.
  4. Use Input > Listen to line-in to start or stop live capture. Select the capture device and audio channel first.
  5. Use Input > Record line-in to WAV... to save the same 48 kHz mono capture while live decoding continues. Stop line-in when finished; the completed WAV can be imported normally or with recovery passes. If capture stops unexpectedly, the app finalizes the recording and reports any disk error in the status bar.

Recovered files remain in the session until you choose File > New cassette.... That command asks for confirmation and can save and back up the current recovery state. If you import another WAV batch while data is present, the app asks whether to add it to the current cassette, start a new cassette, or cancel, so unrelated tapes do not merge silently.

If you later need an earlier session, File > Restore recovery backup... lists timestamped reset backups. Restoring replaces the current session after the usual save/discard/cancel choice and makes a safety backup of the current saved files. Diagnostic waveforms are session-only and are not included.

Understanding results

Complete files have all expected final blocks and can be exported. Partial files may still be useful, but raw-file and disk-image export accepts complete recovered files only. Select a file and inspect its block map and diagnostic waveform when a block has an error.

Export

  • Recovered files and .inf... writes payload-only BBC files and matching metadata.
  • CSW cassette image... writes a cassette image for compatible tools and emulators.
  • BBC Micro disk image... offers DFS SSD/DSD and classic ADFS S/M/L images. The preflight lets you rename or omit entries when names or capacity need adjustment.

Checking for updates

Help > Check for updates manually checks GitHub for the latest stable release. It never downloads or installs anything; if a newer version is found, you can choose whether to open its release page. Checks have a short timeout and can be unavailable when offline or when GitHub rate-limits requests.

The request is sent only when you choose this command and contains no cassette data, recovery state, file paths, or machine identifier. GitHub may still see the request's IP address, time, and application user-agent.

Troubleshooting

  • Try a different Audio channel for stereo recordings.
  • For line-in, confirm that Windows exposes the intended input device and that its level is not muted or excessively clipped.
  • Keep the executable, required DLLs, configuration file, help file, and licence files together in the distribution folder.
  • The decoder currently targets standard 1200-baud BBC cassette files. 300-baud and custom commercial loaders are not currently supported.
